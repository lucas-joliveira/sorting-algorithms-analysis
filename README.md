# Sorting Algorithms Analysis

Análise de desempenho e implementação de algoritmos de ordenação em Python:
- **Selection Sort**
- **Binary Insertion Sort**
- **Heap Sort**

## Como Executar

Para rodar qualquer um dos algoritmos no terminal, execute o script passando o arquivo de entrada com os números como argumento:

### Selection Sort
```bash
python3 selection_sort.py 1000_numbers.txt
```

### Heap Sort
```bash
python3 heap_sort.py 1000_numbers.txt
```

### Binary Insertion Sort
```bash
python3 binary_insertion_sort.py 1000_numbers.txt
```

> **Nota:** É possível substituir `1000_numbers.txt` por `5000_numbers.txt` ou `10000_numbers.txt` para testar com volumes de dados maiores.
